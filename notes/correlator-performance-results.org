* Latest strict median run

This note records the strict correlator benchmark run from 2026-06-08 after
adding indexed NS free-fermion \(\psi^\mu\) cases.  The new cases construct
distinct target-space vector labels and the benchmark rejects a scalar shortcut:
the preflight sink requires every \(\psi^\mu\psi^\nu\) contraction to emit a
metric tensor factor.  The command was:

#+begin_src sh
zig run --global-cache-dir /tmp/zig-global-cache -OReleaseFast --dep cft-code -Mroot=benchmarks/correlator_kernel_median.zig --dep tensor-code -Mcft-code=src/cft-code/cft-code.zig -Mtensor-code=/tmp/tensor_stub.zig
#+end_src

The run exited successfully.  Every event and branch case stayed within the
=21/20= median gate, and every case had primitive/tensor/residual/zero-mode/base-case

* Eta-xi torus check

The eta-xi torus runtime was checked against the stringbook/Verlinde-Lechtenfeld
convention that the pure \(\eta,\xi\) torus sector uses the prime-form
log-derivative kernel together with one extra \(\xi\) zero-mode insertion.  The
benchmark therefore records =elliptic_prime_form_log_derivative= rather than
the prime form itself.

The 2026-06-08 focused run placed the eta-xi torus cases first.  They passed the
count and median gates before a later unrelated legacy gate stopped the full
