#+title: Lisp-Zig Descriptor Vertical Slice Implementation

* Purpose

This node is the implementation spec for the first Lisp-to-Zig vertical slice.
It refines [[id:20260608T180000.000000][Lisp CFT DSL Specification]] and
[[id:20260608T120000.000000][Lisp Endpoint Development Order]].

The goal is not to finish the final Lisp DSL.  The goal is to force the real
boundary into existence:

#+begin_src text
small Lisp CFT declarations
  -> normalized Lisp IR
  -> generated Zig descriptor
  -> Zig comptime lowering
  -> compact runtime tables
  -> runtime correlator
  -> streamed result events
  -> Lisp expression objects or count results
#+end_src

This is the data-gathering slice.  More handwritten Zig presets are not enough
data, because they do not test whether Lisp can generate the boundary.  A full
polished Lisp DSL is also premature.

* Scope

Implement a narrow but real vertical slice:

- Zig descriptor frontend for generated theory data.
- Zig comptime validation and lowering to the existing correlator runtime.
- Runtime symbol preservation for fields, coordinates, labels, tensors, and
  parameters.
- Stable result events suitable for Lisp reconstruction.
- Minimal Common Lisp emitter for a small normalized IR.
- Four mandatory generated fixtures:
  - indexed free fermion with \(\psi^\mu\);
  - eta-xi on sphere and torus;
  - bc on sphere;
  - free boson with label-dependent =expX= weight.

Out of scope for this slice:

- final polished user syntax;
- pure-spinor perturbation theory;
- NLSM perturbation theory;
- full OPE endpoint;
- full basis generation endpoint;
- replacing every handwritten preset.

The slice must leave descriptor slots or clear extension points for OPE,
relations, and basis rules, but it does not need to implement those services.

* AGENTS.md Audit

The implementation run must periodically re-read =AGENTS.md= and explicitly
check the work against it.

Required audit points:

1. Before the first code edit.
2. After the descriptor data structures are designed.
3. Before adding any public declaration.
4. Before adding any test.
5. Before final response.

Each audit should check:

- code is edited through =org= nodes and tangled to =src= when needed;
- public interfaces are minimal;
- generated and runtime data structures are lean;
- no large symbolic expressions are allocated by default;
- data flow remains stream-oriented and parallelizable;
- tests pin concrete invariants rather than syntax trivia.

* Anti-Overfitting Rules

The generic Lisp emitter and generic Zig lowerer must not dispatch on theory
names.

Forbidden in generic code:

- =if theory == eta_xi=;
- =if theory == free_fermion=;
- =if field name == psi=;
- =if field name == xi=;
- theory-specific generated result handling;
- theory-specific ABI entrypoints.

Allowed:

- theory names in generated fixture modules;
- theory names in tests and docs;
- theory names in preset packages;
- theory names in user-visible symbol tables.

If implementation needs a new concept, add a generic primitive.  Examples:

- label role;
- tensor factor;
- elliptic kernel;
- zero-mode kind;
- residual operator event;
- metadata expression kind;
- relation kind.

Run this audit before final:

#+begin_src sh :tangle no
rg -n "eta[-_]xi|free[-_]fermion|free[-_]boson|bc|psi|xi|expX|dX|SO32|spin[-_]field|pure[-_]spinor|NLSM|CY" \
  path/to/generic-lisp-emitter path/to/generic-zig-lowerer
#+end_src

Every match must be classified as allowed or fixed.

* Descriptor Contract

Implement the smallest useful generated descriptor.  It should be boring
machine data, not a user language.

Required descriptor fields:

- theory name and descriptor ABI version;
- parameters;
- surfaces;
- fields;
- field label schemas;
- weight metadata;
- quantum-number metadata;
- Wick rules;
- zero-mode rules;
- result symbols.

Reserved descriptor fields:

- OPE rules;
- operator templates;
- relation rules;
- basis rules.

Reserved fields may be empty and may lower to unsupported-service errors.  They
must exist so the ABI shape does not need to be rethought for pure spinor,
spin fields, and \((2,2)\) bases.

* Zig Tasks

** Descriptor Data

Add a generated descriptor frontend in the appropriate =org= source node.

The frontend should define:

- dense ids for surfaces, fields, labels, parameters, and result symbols;
- label roles at least for vector index, momentum, profile, scalar parameter,
  and modular parameter;
- surface kinds at least sphere and torus;
- coordinate models rational and elliptic;
- metadata expressions for rational constants, parameters, labels, arithmetic,
  and bilinear forms;
- Wick factor terms for scalar factors, coordinate kernels, tensor factors,
  action/profile factors, and residual original-side factors;
- zero-mode kinds for constant fermion, top-form fermion, and boson momentum
  conservation.

** Validation

Validate at comptime:

- ids are dense and unique;
- referenced surfaces, fields, labels, parameters, and symbols exist;
- Wick rule field arity matches field declarations;
- tensor factors reference compatible label roles;
- zero-mode declarations reference compatible fields;
- weight metadata can reference field labels such as momentum \(k\);
- unsupported reserved services fail with clear diagnostics.

** Lowering

Lower descriptor data to the existing private runtime tables.

Do not expose runtime table types just to make generation easier.  The lowerer
is the boundary between generated descriptor data and private internals.

The lowerer should preserve:

- current branch traversal behavior;
- current fermion signs;
- current zero-mode base cases;
- current pair lookup performance shape;
- current product/boundary composition behavior where applicable.

** Result Events

Expose a small stable event stream for Lisp.

Required modes:

- count only;
- streamed callback;
- bounded collection through Lisp.

Events must identify:

- scalar factors;
- coordinate factors with original coordinate symbols;
- tensor factors with original label symbols;
- zero-mode factors;
- residual operators;
- term and sum boundaries.

Zig must not build large symbolic expression trees by default.

** ABI

Expose only the minimum generated-theory ABI:

- descriptor ABI version;
- theory hash;
- context create/destroy;
- symbol interning;
- field insertion;
- normal ordering;
- operator-list freeze;
- correlator run;
- correlator count;
- last error.

The ABI should be theory-generic.  Field ids and symbol ids distinguish
generated theories at runtime.

* Lisp Tasks

Implement a minimal Common Lisp package after the Zig descriptor frontend is
usable.

Required Lisp pieces:

- normalized IR structs or classes;
- simple declaration constructors;
- role inference for ordinary coordinates and labels;
- deterministic descriptor ordering;
- generated Zig descriptor emission;
- build/cache manifest;
- CFFI loading;
- symbol interning;
- field constructor wrappers;
- correlator call wrappers;
- streamed result to Lisp expression conversion;
- count-only result path.

The first Lisp surface may be modest.  It does not need to be the final crisp
syntax.  It must nevertheless prove that Lisp owns theory declarations and Zig
does not get a second user-facing DSL.

* Fixtures

** Indexed Free Fermion

Mandatory fixture:

#+begin_src lisp :tangle no
(defcft free-fermion-10
  (source stringbook)
  (sphere)
  (fermion psi (mu z) :h 1/2)
  (wick (psi mu z) (psi nu w)
    (/ (eta mu nu) (- z w))))
#+end_src

Acceptance:

- result contains tensor factor \(\eta_{\mu\nu}\);
- coordinate names =z= and =w= survive;
- index names =mu= and =nu= survive;
- no scalar-only shortcut is used;
- benchmark still satisfies the required speedup on Mathematica-slow cases
  once benchmark comparison is available.

** Eta-Xi

Mandatory fixture:

#+begin_src lisp :tangle no
(defcft eta-xi
  (source stringbook)
  (sphere)
  (torus tau)
  (fermion eta (z) :h 1)
  (fermion xi  (z) :h 0 :zero constant)
  (wick (eta z) (xi w)
    (/ 1 (- z w)))
  (wick (eta z) (xi w) :on (torus tau)
    (prime-log-d z w tau)))
#+end_src

Acceptance:

- sphere result matches existing eta-xi behavior;
- torus result uses
  \(\langle \eta(z)\xi(w)\rangle = \partial_z \log E(z,w|\tau)\);
- xi zero mode is represented by generic constant-fermion zero-mode data;
- no generic lowerer code checks for eta-xi by name.

** bc

Mandatory fixture:

#+begin_src lisp :tangle no
(defcft bc
  (source stringbook)
  (sphere)
  (fermion b (z) :h 2)
  (fermion c (z) :h -1 :zero top-form)
  (wick (b z) (c w)
    (/ 1 (- z w))))
#+end_src

Acceptance:

- sphere result matches existing bc behavior;
- top-form zero mode is represented by generic top-form-fermion zero-mode
  data;
- coordinate names =z= and =w= survive;
- no generic lowerer code checks for bc, b, or c by name.

** Free Boson

Mandatory fixture:

#+begin_src lisp :tangle no
(defcft free-boson-10
  (source stringbook)
  (dimension 10)
  (parameter alpha-prime 1)
  (sphere)

  (boson dX  (mu z)  :h 1)
  (boson dXb (mu zb) :hbar 1)
  (primary expX (k z zb)
    :h    (* 1/4 alpha-prime (dot k k))
    :hbar (* 1/4 alpha-prime (dot k k))
    :zero constant)

  (wick (dX mu z) (dX nu w)
    (* -1/2 alpha-prime (eta mu nu) (pow (- z w) -2)))

  (wick (dX mu z) (expX k w wb)
    (* -1/2 alpha-prime i (p k mu) (pow (- z w) -1)))

  (wick (expX p z zb) (expX k w wb)
    (* (pow (- z w)   (* 1/2 alpha-prime (dot p k)))
       (pow (- zb wb) (* 1/2 alpha-prime (dot p k))))))
#+end_src

Acceptance:

- =dX dX= result contains tensor factor \(\eta_{\mu\nu}\);
- =expX= weight depends on supplied \(k^2\);
- on-shell assumptions are calculation assumptions, not field declarations;
- boson constant mode is represented by generic boson momentum-conservation
  data;
- no generic lowerer code checks for free-boson, dX, or expX by name.

* Tests

Add tests only for concrete invariants:

- descriptor validation rejects duplicate ids;
- descriptor validation rejects dangling references;
- generated free-fermion result emits tensor and coordinate events;
- generated eta-xi zero mode lowers through generic constant-fermion data;
- generated bc zero mode lowers through generic top-form-fermion data;
- generated free-boson constant mode lowers through generic
  momentum-conservation data;
- generated free-boson =expX= weight metadata references the momentum label;
- result event names round-trip to Lisp;
- count-only mode does not allocate a Lisp expression object;
- anti-overfitting audit passes for generic lowerer and emitter.

Do not add tests merely to exercise language syntax.

* Benchmarks

Benchmark only after the generated path can run the mandatory fixtures.

Required benchmark checks:

- generated free-fermion path does not regress handwritten free-fermion path;
- generated eta-xi path does not regress handwritten eta-xi path;
- generated bc path does not regress handwritten bc path;
- generated free-boson path does not regress handwritten free-boson path;
- the psi-indexed benchmark still compares against the Mathematica prototype
  on cases where Mathematica takes more than one second;
- the target remains greater than \(10\,000\times\) speedup for those cases.

* Stop Conditions

Stop and report if one of these happens:

- the descriptor needs theory-name branches to lower the mandatory fixtures;
- the result event stream cannot preserve user symbols without changing the
  runtime representation;
- the minimal ABI would require exposing private runtime table types;
- the generated path cannot match existing handwritten behavior for the
  mandatory fixtures;
- AGENTS.md conflicts with a planned implementation step.

Do not stop merely because generated Zig is ugly.

* Final Deliverables

At completion, report:

- files changed;
- generated descriptor shape;
- Lisp package shape;
- fixtures implemented;
- tests and benchmarks run;
- anti-overfitting audit result;
- AGENTS.md audit result;
- remaining work before the polished DSL.
