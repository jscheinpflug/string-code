This note inserts the missing contraction-side summary layer between
[[id:20260609T212500.000000][NLSM Diagram Plan]] and
[[id:20260609T215000.000000][NLSM Kernel Signature Reducer]].  It does not enumerate full Wick branches yet.
It counts the quantum species carried by one candidate multiset, rejects
unpairable candidates, and emits a compact signature row that a later explicit
pairing engine can refine without changing the downstream kernel or pole APIs.

The stage is target-agnostic.  CY3 and K3 later change target quotients and
vertex catalogs, not the basic statement that \(\xi\), \(\psi_L\), and
\(\psi_R\) must pair consistently.
