* What Is Not Done

Ignoring spinors, the missing piece is still a general local Brauer morphism
compiler.  The current code reaches the Brauer core through several adapter
branches:

#+begin_src text :tangle no

#+end_src

Those branches are descriptor-based, not closed-form Weyl/hook formulas, but
they are still narrower than the final tensor-only solver.  The final
tensor-only solver should compile the same object for every supported
non-spinor local channel:

#+begin_src text :tangle no

  -> endpoint projector factors

  -> independent pivots

#+end_src

The hard part is not the row/column Young algebra anymore.  The hard part is
the universal candidate generator and its streaming representation.

* Universal Brauer Diagram Model

For a tensor-only morphism
\[
  E : L \otimes R \to O
\]
let

#+begin_src text :tangle no
input slots  = left slots followed by right slots
output slots = output slots
#+end_src

A raw Brauer diagram is a perfect matching of all boundary slots.  Edges have
three kinds:

#+begin_src text :tangle no
input-output edge   -> delta
input-input edge    -> metric contraction on inputs
output-output edge  -> metric insertion on outputs
#+end_src

The parity condition is:

#+begin_src text :tangle no
input_slot_count + output_slot_count must be even
#+end_src

If parity fails, there is no tensor-only invariant.  The caller should see
=UnsupportedTensorBridge= unless decomposition says this channel should never
have been requested.

* Raw Diagram Enumeration

The raw enumerator should be iterative or bounded-recursive over a bitset.  It
must deduplicate diagrams canonically and stop at the candidate cap.

#+begin_src zig :tangle no
fn enumerateRawBrauerDiagrams(channel: TensorOnlyChannel, out: *TensorBrauerDiagramBuffer) !void {
    const total = channel.input_slot_count + channel.output_slot_count;
    if (total > 2 * max_tensor_slots) return error.UnsupportedTensorShapeOverCap;
    if ((total & 1) != 0) return error.UnsupportedTensorBridge;

    var used_mask: u32 = 0;
    var diagram: TensorBrauerDiagram = .{};
    try enumerateRawBrauerDiagramsRec(channel, total, used_mask, &diagram, out);
    try uniqueTensorBrauerDiagrams(out);
}

fn enumerateRawBrauerDiagramsRec(
    channel: TensorOnlyChannel,
    total: u8,
    used_mask: u32,
    diagram: *TensorBrauerDiagram,
    out: *TensorBrauerDiagramBuffer,
) !void {
    const first = firstUnusedSlot(total, used_mask) orelse {
        try out.append(try canonicalTensorBrauerDiagram(diagram.*));
        return;
    };

    var second = first + 1;
    while (second < total) : (second += 1) {
        if (slotUsed(used_mask, second)) continue;
        const edge = try tensorBrauerEdgeFromBoundarySlots(channel, first, second);
        diagram.push(edge) catch |err| return err;
        try enumerateRawBrauerDiagramsRec(
            channel,
            total,
            markUsed(markUsed(used_mask, first), second),
            diagram,
            out,
        );
        diagram.pop();
    }
}
#+end_src

The edge converter maps the combined boundary index to the existing primitive
edge vocabulary:

#+begin_src zig :tangle no
fn tensorBrauerEdgeFromBoundarySlots(channel: TensorOnlyChannel, a: u8, b: u8) !TensorBrauerEdge {
    const a_is_input = a < channel.input_slot_count;
    const b_is_input = b < channel.input_slot_count;

    if (a_is_input and b_is_input) {
        return .{ .input_metric = .{ .left = a, .right = b } };
    }

    if (!a_is_input and !b_is_input) {
        return .{ .output_metric = .{
            .left = a - channel.input_slot_count,
            .right = b - channel.input_slot_count,
        } };
    }

    const input = if (a_is_input) a else b;
    const output_boundary = if (a_is_input) b else a;
    return .{ .delta = .{
        .input = input,
        .output = output_boundary - channel.input_slot_count,
    } };
}
#+end_src

This single enumerator subsumes the current output-projector, scalar-pairing,
and contraction branches.

* Endpoint Projectors

Each non-spinor endpoint gets a projector factor.  The projector is itself a
small Brauer program on that endpoint's slots:

#+begin_src text :tangle no
scalar endpoint       -> identity projector with zero slots
vector_young endpoint -> trace-free Young projector for its shape
exterior_form         -> single-column trace-free Young projector
mixed_tensor_form     -> Young shape obtained from form profile
hodge_form            -> form projector plus Hodge/epsilon factor
#+end_src

Pseudocode:

#+begin_src zig :tangle no
fn endpointProjector(endpoint: TensorOnlyEndpoint, dimension: u16) !EndpointProjector {
    if (endpoint.slot_count == 0) return scalarEndpointProjector();
    if (endpoint.slot_count > max_tensor_slots) return error.UnsupportedTensorShapeOverCap;

    var young_candidates: BrauerCandidateBuffer = .{};
    try appendVectorYoungPermutationCandidates(endpoint.shape(), endpoint.slot_count, &young_candidates);
    try uniqueBrauerWords(&young_candidates);
    if (young_candidates.count != 1) return error.UnsupportedTensorBridge;

    var projector = try traceFreeBrauerProjectorBasisForShape(
        endpoint.shape(),
        dimension,
        young_candidates.candidates[0],
    );

    if (endpoint.duality != .none) {
        try attachHodgeProjector(&projector, endpoint);
    }

    return endpointProjectorFromTraceFreeBasis(projector);
}
#+end_src

Do not attach endpoint projectors by expanding them into the global candidate
list.  Store projector factors and apply them lazily during Gram and
streaming.

* Candidate Word Construction

For each raw diagram \(D\), the candidate word is the factorized sandwich:

#+begin_src text :tangle no
P_output * D * (P_left tensor P_right)
#+end_src

Pseudocode:

#+begin_src zig :tangle no
fn enumerateTensorOnlyCandidates(program: *TensorOnlyProgram) !void {
    var raw_index: u8 = 0;
    while (raw_index < program.raw_diagram_count) : (raw_index += 1) {
        var word: TensorOnlyCandidateWord = .{ .coefficient = Rational.one() };

        if (!endpointProjectorIsIdentity(program.left_projector))
            try word.append(.{ .kind = .left_projector, .candidate_index = 0 });

        if (!endpointProjectorIsIdentity(program.right_projector))
            try word.append(.{ .kind = .right_projector, .candidate_index = 0 });

        try word.append(.{ .kind = .raw_brauer_diagram, .candidate_index = raw_index });

        if (!endpointProjectorIsIdentity(program.output_projector))
            try word.append(.{ .kind = .output_projector, .candidate_index = 0 });

        if (channelHasHodgeEndpoint(program.channel))
            try appendHodgeFactors(&word, program.channel);

        try appendUniqueTensorOnlyCandidate(program, word);
    }
}
#+end_src

The order is logical, not necessarily materialized order.  The Gram compiler
interprets the factors as a morphism composition.

* Exact Gram

The Gram entry is computed by composing diagrams, not by evaluating tensor
components.

#+begin_src zig :tangle no
fn tensorOnlyCandidateInnerProduct(program: *const TensorOnlyProgram, a: TensorOnlyCandidateWord, b: TensorOnlyCandidateWord) !Rational {
    var graph: TensorBrauerComposition = .{};
    try graph.init(program.channel);

    try applyTensorOnlyWord(&graph, program, a, .forward);
    try applyTensorOnlyWord(&graph, program, b, .adjoint);

    if (graph.is_zero) return Rational.zero();

    var value = try a.coefficient.mul(b.coefficient);
    value = try value.mul(try powRational(program.channel.dimension, graph.loop_count));
    value = try value.mul(graph.hodge_scale);
    return value;
}
#+end_src

The graph state should be arrays, not maps:

#+begin_src zig :tangle no
const TensorBrauerComposition = struct {
    parent: [max_tensor_composition_nodes]u8,
    loop_count: u8,
    hodge_scale: Rational,
    is_zero: bool,
};
#+end_src

The existing =BrauerContraction= and =tensorContractionWordInnerProduct= are
the starting point.  Generalize them to arbitrary input/output boundary counts
instead of keeping separate projector/pairing/contraction entry points.

* Pivot And Inverse Gram

Reuse the exact pivot and inverse routines already present:

#+begin_src zig :tangle no
fn finishTensorOnlyProgram(program: *TensorOnlyProgram) !void {
    var gram: [max_tensor_candidates * max_tensor_candidates]Rational = zeroGram();

    var row: u8 = 0;
    while (row < program.candidate_count) : (row += 1) {
        var column: u8 = 0;
        while (column <= row) : (column += 1) {
            const value = try tensorOnlyCandidateInnerProduct(
                program,
                program.candidates[row],
                program.candidates[column],
            );
            gram[row * program.candidate_count + column] = value;
            gram[column * program.candidate_count + row] = value;
        }
    }

    const pivots = try selectIndependentGramPivots(program.candidate_count, gram[0..]);
    if (pivots.count == 0) return error.UnsupportedTensorBridge;
    if (pivots.count > max_tensor_pivots) return error.UnsupportedTensorPivotCap;

    program.pivots = copyPivots(pivots);
    program.pivot_count = pivots.count;
    program.inverse_gram = try invertPivotSubgram(program.candidate_count, gram[0..], pivots);
    program.term_count = try countTensorOnlyTerms(program);
}

* Streaming

Streaming walks pivot pairs and factorized candidate words.  It must not
materialize the whole expanded expression.

#+begin_src zig :tangle no
fn appendTensorOnlyTerm(
    allocator: Allocator,
    atoms: *ArrayList(SymbolicAtom),
    program: *const TensorOnlyProgram,
    term_index: u16,
) !RationalId {
    var seen: u16 = 0;
    var row: u8 = 0;
    while (row < program.pivot_count) : (row += 1) {
        var column: u8 = 0;
        while (column < program.pivot_count) : (column += 1) {
            const coefficient = program.inverse_gram[row * program.pivot_count + column];
            if (coefficient.numerator == 0) continue;

            const left = program.candidates[program.pivots[row]];
            const right = program.candidates[program.pivots[column]];
            const pair_count = try countTensorOnlyWordPairTerms(program, left, right, coefficient);
            if (term_index < seen + pair_count) {
                return appendTensorOnlyWordPairTerm(
                    allocator,
                    atoms,
                    program,
                    left,
                    right,
                    coefficient,
                    term_index - seen,
                );
            }
            seen += pair_count;
        }
    }
    return error.ProjectorConstructorTermOutOfBounds;
}
#+end_src

The inner streamer expands only the selected factor product:

#+begin_src zig :tangle no
fn appendTensorOnlyWordPairTerm(
    allocator: Allocator,
    atoms: *ArrayList(SymbolicAtom),
    program: *const TensorOnlyProgram,
    left: TensorOnlyCandidateWord,
    right: TensorOnlyCandidateWord,
    coefficient: Rational,
    local_index: u16,
) !RationalId {
    var iterator = TensorOnlyFactorProductIterator.init(program, left, right, coefficient);
    while (try iterator.nextSkipping(local_index)) |primitive| {
        switch (primitive.kind) {
            .delta => try appendVectorSlotDelta(allocator, atoms, program.channel, primitive),
            .metric => try appendVectorSlotMetric(allocator, atoms, program.channel, primitive),
            .hodge => try appendHodgePrimitive(allocator, atoms, program.channel, primitive),
        }
    }
    return rationalToRenderingId(iterator.currentCoefficient());
}

* Performance Rules

Do this:

#+begin_src text :tangle no

cache tensor-only programs by compact channel key
store candidates as factorized words
compute Gram entries by diagram composition into fixed arrays
stream one selected pivot-pair/factor-product term at a time
deduplicate diagrams and words immediately at each bounded stage
return typed cap errors before allocating large buffers

Do not do this:

#+begin_src text :tangle no

do not build dense symbolic expression trees

* How This Later Joins The Spinor Solver

The tensor-only solver should expose one private function shaped like:

#+begin_src zig :tangle no
fn compileTensorOnlyBrauerProgram(channel: TensorOnlyChannel) !TensorOnlyProgram;
#+end_src

The spinor solver should later join at the candidate-word/factor level, not by
calling tensor-only streaming as a black box.  The future mixed solver should
compose:

#+begin_src text :tangle no
tensor-only Brauer factors
Clifford/gamma factors
spinor pairing factors
Hodge factors
#+end_src

This is why tensor-only candidates must remain factorized.  If tensor-only
terms are eagerly expanded into primitive atom lists, mixed tensor-spinor
Gram entries will have to re-parse streamed atoms or duplicate the compiler.

The fast spinor path remains authoritative until the mixed solver proves
performance parity:

#+begin_src text :tangle no
spinor_clifford_bridge -> existing structural Clifford cache
tensor_only_channel    -> tensor-only Brauer program
future mixed channel   -> shared factorized candidate-word solver
#+end_src
