NLSM Component RNC Expansion

  • Lowering Convention For Raw Fermion Derivatives

This note adds the first real component-level source table behind the RNC vertex generator. The goal is narrow: replace the fully hand-written finished vertex catalog by a source table whose rows still remember which component term they came from.

This is not yet the full type-II expansion. It is the first explicit slice:

  • bosonic kinetic term;
  • bosonic \(R\,\xi^2 \partial X_0 \bar\partial X_0\) term;
  • bosonic \(\nabla R\,\xi^3 \partial X_0 \bar\partial X_0\) term;
  • bosonic \(\nabla^2 R\,\xi^4 \partial X_0 \bar\partial X_0\) term;
  • bosonic \(R^2 \xi^4 \partial X_0 \bar\partial X_0\) term;
  • left/right fermion-connection terms \(\bar\partial X_0\,\xi\,\psi_L\psi_L\,R\), \(\partial X_0\,\xi\,\psi_R\psi_R\,R\), \(\bar\partial X_0\,\xi^2\,\psi_L\psi_L\,\nabla R\), \(\partial X_0\,\xi^2\,\psi_R\psi_R\,\nabla R\);
  • raw metric-expansion fermion-derivative terms \(\xi^2\,\psi_L\,\bar\partial\psi_L\,R\), \(\xi^2\,\psi_R\,\partial\psi_R\,R\), stored on a contact-only channel;
  • the \(N=(1,1)\) quartic fermion-curvature term.

That is enough to stop pretending the metric-sector source is just a finished row list, while still keeping the code lean and stream-first.

The mixed fermion rows are the first terms generated by expanding the target connection in \[ Gμν(X)ψ^μ {\cal D}\bar zψ^ν

  • Gμν(X)\widetildeψ^μ {\cal D}z\widetildeψ^ν

\] about \(X_0\) in real RNC. Since \(\Gamma^\mu{}_{\nu\rho}(X_0)=0\), the first nontrivial terms come from the Taylor series of the connection itself, \[ Γ^μνρ(X0+ξ) = -{1\over 3}\big(R^μνρσ+R^μρνσ\big)ξ^σ -{1\over 6}∇λ \big(R^μνρσ+R^μρνσ\big)ξ^σξ^λ

  • ⋯.

\] This is why the mixed \(R\) rows carry coefficient \(-1/3\), and the mixed \(\nabla R\) rows carry coefficient \(-1/6\). The current source table keeps only the terms with one surviving background leg \(\partial X_0\) or \(\bar\partial X_0\), because those are the first mixed vertices needed by the metric-counterterm pipeline already implemented downstream.

Explicit Vertex Families

This section writes the actual local vertices used by the current source table. The code below does not try to re-derive them symbolically. Instead, it stores the field content, background legs, tensor family, and rational coefficient for each term in a compact streamed row. The formulas here fix what those rows mean.

We keep only the terms relevant to the present metric-counterterm pipeline, namely those with surviving background legs \(\partial X_0\) and \(\bar\partial X_0\), together with the quartic fermion-curvature term. Up to overall conventions already fixed in the component action note, the vertices currently implemented are:

  1. Free bosonic kinetic term

\[ V_{\rm kin}^{(\xi)} = g_{\mu\nu}(X_0)\,\partial \xi^\mu\,\bar\partial \xi^\nu. \]

This is the quadratic term that defines the free bosonic propagator.

  1. Bosonic curvature mass vertex

\[ V_{R\xi^2} = {1\over 3}\, R_{\mu\rho\sigma\nu}(X_0)\, \xi^\rho \xi^\sigma\, \partial X_0^\mu \bar\partial X_0^\nu. \]

The row therefore carries coefficient \(+1\) and symmetry denominator \(3\).

  1. Bosonic first-derivative curvature vertex

\[ V_{\nabla R\,\xi^3} = {1\over 6}\, \nabla_\lambda R_{\mu\rho\sigma\nu}(X_0)\, \xi^\lambda \xi^\rho \xi^\sigma\, \partial X_0^\mu \bar\partial X_0^\nu. \]

The row carries coefficient \(+1\) and symmetry denominator \(6\).

  1. Bosonic second-derivative curvature vertex

\[ V_{\nabla^2 R\,\xi^4} = {1\over 20}\, \nabla_\kappa \nabla_\lambda R_{\mu\rho\sigma\nu}(X_0)\, \xi^\kappa \xi^\lambda \xi^\rho \xi^\sigma\, \partial X_0^\mu \bar\partial X_0^\nu. \]

The row carries coefficient \(+1\) and symmetry denominator \(20\).

  1. Bosonic \(R^2 \xi^4\) vertex

\[ V_{R^2\xi^4} = {2\over 45}\, R_{\mu\rho\sigma\alpha}(X_0)\, R^\alpha{}_{\lambda\kappa\nu}(X_0)\, \xi^\rho \xi^\sigma \xi^\lambda \xi^\kappa\, \partial X_0^\mu \bar\partial X_0^\nu. \]

This is the first composite-curvature bosonic vertex in the current table, so the row carries coefficient \(2\) and symmetry denominator \(45\).

  1. Left-moving connection-curvature mixed vertex

\[ V^{(L)}_{\Gamma \sim R\xi} = -{1\over 3}\, \bar\partial X_0^\rho\, \big(R_{\mu\rho\nu\sigma}+R_{\nu\rho\mu\sigma}\big)(X_0)\, \xi^\sigma\, \psi_L^\mu \psi_L^\nu. \]

The code stores this as one \(\xi\), two left-moving fermions, one surviving \(\bar\partial X_0\) leg, one Riemann tensor, coefficient \(-1\), denominator \(3\).

  1. Right-moving connection-curvature mixed vertex

\[ V^{(R)}_{\Gamma \sim R\xi} = -{1\over 3}\, \partial X_0^\rho\, \big(R_{\mu\rho\nu\sigma}+R_{\nu\rho\mu\sigma}\big)(X_0)\, \xi^\sigma\, \psi_R^\mu \psi_R^\nu. \]

This is the right-moving copy of the previous vertex, differing only in the surviving background leg and fermion chirality.

  1. Left-moving first-derivative connection-curvature mixed vertex

\[ V^{(L)}_{\Gamma \sim \nabla R\,\xi^2} = -{1\over 6}\, \bar\partial X_0^\rho\, \nabla_\lambda \big(R_{\mu\rho\nu\sigma}+R_{\nu\rho\mu\sigma}\big)(X_0)\, \xi^\lambda \xi^\sigma\, \psi_L^\mu \psi_L^\nu. \]

The row carries coefficient \(-1\), denominator \(6\), two \(\xi\) fields, two left-moving fermions, and one covariant-derivative Riemann tensor.

  1. Right-moving first-derivative connection-curvature mixed vertex

\[ V^{(R)}_{\Gamma \sim \nabla R\,\xi^2} = -{1\over 6}\, \partial X_0^\rho\, \nabla_\lambda \big(R_{\mu\rho\nu\sigma}+R_{\nu\rho\mu\sigma}\big)(X_0)\, \xi^\lambda \xi^\sigma\, \psi_R^\mu \psi_R^\nu. \]

This is again the chirality-reflected copy of the left-moving vertex.

  1. Quartic fermion-curvature vertex

\[ V_{\psi^2\widetilde\psi^2 R} = {1\over 4}\, R_{\mu\nu\rho\sigma}(X_0)\, \psi_L^\mu \psi_L^\nu \psi_R^\rho \psi_R^\sigma. \]

At the current row level we only need the field content and the attached Riemann tensor. The overall normalization convention of the component action is fixed once, and the row therefore carries the corresponding single-tensor quartic fermion entry.

  1. Left-moving raw metric-derivative fermion vertex

\[ V^{(L)}_{g\xi^2\psi\bar\partial\psi} = {1\over 3}\, R_{\mu\rho\sigma\nu}(X_0)\, \xi^\rho\xi^\sigma\, \psi_L^\mu \bar\partial \psi_L^\nu. \]

  1. Right-moving raw metric-derivative fermion vertex

\[ V^{(R)}_{g\xi^2\psi\partial\psi} = {1\over 3}\, R_{\mu\rho\sigma\nu}(X_0)\, \xi^\rho\xi^\sigma\, \psi_R^\mu \partial \psi_R^\nu. \]

These last two rows are real component vertices, and the source table now keeps them explicitly. They are not emitted on the primitive lowering channel. Instead they are tagged as contact_only, because in the current free chiral scheme they only hit the singular propagator through a contact derivative, \[ \bar\partial_z {1\over z-w} = 2\pi \delta^2(z-w), \qquad \partial_z {1\over \bar z-\bar w} = 2\pi \delta^2(z-w), \] up to the standard distributional convention for the right-moving copy. That is enough to say what they are and where they belong in the calculation, without pretending that they are ordinary primitive Wick kernels.

These ten displayed vertices are exactly the families presently emitted for the \(N=(1,1)\) source table. The next missing sector is not another bosonic mass-type term. It is the differentiated-fermion sector coming from the metric expansion inside \(g_{\mu\nu}(X)\psi^\mu \bar\partial \psi^\nu\) and its right-moving partner.

The primitive free-field blocker is now gone: cft-code carries arbitrary chiral fermion derivative order as data. The remaining missing step is more specific. The raw component action is written with \(\bar\partial \psi_L\) and \(\partial \psi_R\), whereas the free chiral correlator language is organized around holomorphic derivatives of \(\psi_L(z)\) and antiholomorphic derivatives of \(\psi_R(\bar z)\). Before new rows are added here, that lowering convention has to be written explicitly in the note rather than smuggled into the source table.

Lowering Convention For Raw Fermion Derivatives

The next missing component sector begins with the metric expansion inside the fermion kinetic bilinear, \[ G_{\mu\nu}(X)\psi_L^\mu \bar\partial \psi_L^\nu \qquad\text{and}\qquad G_{\mu\nu}(X)\psi_R^\mu \partial \psi_R^\nu. \] In real RNC, the first nontrivial coefficient from the metric itself is \[ Gμν(X) = Gμν(X0)

  • {1\over 3}Rμρσν(X0)ξ^ρξ^σ
  • ⋯,

\] so the raw component vertices would start as \[ V^{(L)}_{g\xi^2\psi\bar\partial\psi} = {1\over 3}\, R_{\mu\rho\sigma\nu}(X_0)\, \xi^\rho\xi^\sigma\, \psi_L^\mu \bar\partial \psi_L^\nu, \] \[ V^{(R)}_{g\xi^2\psi\partial\psi} = {1\over 3}\, R_{\mu\rho\sigma\nu}(X_0)\, \xi^\rho\xi^\sigma\, \psi_R^\mu \partial \psi_R^\nu. \]

At the level of the free chiral theory, however, the singular fermion two-point functions are \[ \langle \psi_L(z)\psi_L(w)\rangle \sim {1\over z-w}, \qquad \langle \psi_R(\bar z)\psi_R(\bar w)\rangle \sim {1\over \bar z-\bar w}. \] Therefore the primitive differentiated kernels are obtained by acting with \(\partial_z,\partial_w\) on the left-moving pair and \(\partial_{\bar z},\partial_{\bar w}\) on the right-moving pair. A raw \(\bar\partial\psi_L\) or \(\partial\psi_R\) does not directly define such a primitive singular kernel. Away from contact terms, it annihilates the free chiral propagator. Any remaining contact contribution belongs to the regularization/contact-term policy, not to the primitive free-field inventory.

This fixes the present lowering convention:

  1. a raw worldsheet derivative on a chiral fermion is not lowered automatically to a primitive pair kernel of the opposite chirality;
  2. the raw \(g\xi^2\psi\bar\partial\psi\) and \(g\xi^2\psi\partial\psi\) vertices are retained in the component source table, but on a separate contact_only channel;
  3. only rows on the primitive channel are emitted by the present streamSources API used by rnc_vertices;
  4. a future contact-term evaluator may request the contact_only rows explicitly and combine them with the regularization layer.

This is why the present primitive source emission still stops at the connection-generated fermion vertices and the quartic fermion-curvature term, even though the component table itself now also records the raw metric fermion-derivative rows.

The source module now enforces this boundary directly: only primitive rows are required to satisfy the chiral lowering rule that every left-moving fermion carries zero antiholomorphic derivative count and every right-moving fermion carries zero holomorphic derivative count. The raw metric fermion-derivative rows violate that rule by construction, so they are stored on the separate contact_only channel instead of being mis-lowered.

pub const SourceWorldsheet = enum(u8) {

pub const SourceFieldKind = enum(u8) {
    xi,
    psi_left,
    psi_right,

    d_x0,

/// SourceLoweringChannel records whether a source row lowers to primitive Wick kernels or only to contact terms.

    primitive,

    holomorphic: u4 = 0,
    antiholomorphic: u4 = 0,
};

};

fn fieldMatchesCurrentLowering(field: SourceField) bool {
    return switch (field.kind) {
        .xi => true,
        .psi_left => field.derivatives.antiholomorphic == 0,
        .psi_right => field.derivatives.holomorphic == 0,
    };
}

fn rowMatchesCurrentLowering(row: ComponentSourceRow) bool {
    for (row.fields) |field| {
        if (!fieldMatchesCurrentLowering(field)) return false;
    }
    return true;
}

fn matchesRequest(row: ComponentSourceRow, request: SourceRequest) bool {
    if (row.worldsheet != request.worldsheet) return false;
    if (row.channel == .contact_only and !request.include_contact_only) return false;
    if (row.xi_order > request.max_xi_order) return false;
    if (!request.include_higher_metric_terms) switch (row.family) {
        .kinetic, .riemann_mass, .fermion_connection_riemann, .fermion_metric_derivative_riemann, .fermion_riemann => {},
        .nabla_riemann_mass, .nabla2_riemann_mass, .riemann_square_mass, .fermion_connection_nabla_riemann => return false,
    };
    if (request.include_fermions) return true;
    for (row.fields) |field| switch (field.kind) {
        .psi_left, .psi_right => return false,
        .xi => {},
    };
    return true;
}

/// streamSources emits the first explicit component RNC source families.
pub fn streamSources(request: SourceRequest, sink: anytype) !void {
    for (source_rows) |row| {
        if (!matchesRequest(row, request)) continue;
        if (row.channel == .primitive and !rowMatchesCurrentLowering(row)) {
            return error.UnsupportedFermionDerivativeLowering;
        }
        try sink.emit(row);
    }
}

test "contact-only differentiated fermion metric rows are opt-in" {
    const testing = std.testing;
    const Sink = struct {
        rows: []ComponentSourceRow,
        count: usize = 0,

        fn emit(self: *@This(), row: ComponentSourceRow) !void {
            if (self.count == self.rows.len) return error.OutputTooSmall;
            self.rows[self.count] = row;
            self.count += 1;
        }
    };

    var primitive_rows: [16]ComponentSourceRow = undefined;
    var primitive_sink = Sink{ .rows = &primitive_rows };
    try streamSources(.{
        .worldsheet = .n1_1,
        .max_xi_order = 2,
        .include_fermions = true,
        .include_higher_metric_terms = true,
    }, &primitive_sink);
    try testing.expectEqual(@as(usize, 6), primitive_sink.count);
    for (primitive_rows[0..primitive_sink.count]) |row| {
        try testing.expectEqual(SourceLoweringChannel.primitive, row.channel);
    }

    var all_rows: [16]ComponentSourceRow = undefined;
    var all_sink = Sink{ .rows = &all_rows };
    try streamSources(.{
        .worldsheet = .n1_1,
        .max_xi_order = 2,
        .include_fermions = true,
        .include_higher_metric_terms = true,
        .include_contact_only = true,
    }, &all_sink);
    try testing.expectEqual(@as(usize, 8), all_sink.count);

    var found_left_raw = false;
    var found_right_raw = false;
    for (all_rows[0..all_sink.count]) |row| {
        if (row.family != .fermion_metric_derivative_riemann) continue;
        try testing.expectEqual(SourceLoweringChannel.contact_only, row.channel);
        if (row.fields.len != 4) continue;
        if (row.fields[2].kind == .psi_left and row.fields[3].kind == .psi_left and row.fields[3].derivatives.antiholomorphic == 1) {
            found_left_raw = true;
        }
        if (row.fields[2].kind == .psi_right and row.fields[3].kind == .psi_right and row.fields[3].derivatives.holomorphic == 1) {
            found_right_raw = true;
        }
    }
    try testing.expect(found_left_raw);
    try testing.expect(found_right_raw);
}
